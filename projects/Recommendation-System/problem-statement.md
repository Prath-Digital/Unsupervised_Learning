# Recommendation System

## Problem 1: Apriory

What should we recommend when a customer buys a particular product?
Example:

> Customer buys: Milk
> Recommended: Bread, Cereal, Butter, Cookies

## Problem 2: Content-Based Filtering

Given a product a customer is interested in, recommend other products having similar characteristics.

Example:

User views:
Wireless Headphones

Recommend:

> Bluetooth Earbuds
> Wireless Speakers
> Noise-Cancelling Headphones

## Problem 3: Collaborative Filtering

Recommend products to a user based on the preferences and interactions of users with similar behavior.

Example:

> User A:
> Milk ⭐⭐⭐⭐⭐
> Bread ⭐⭐⭐⭐⭐
> Butter ⭐⭐⭐⭐
>
> User B:
> Milk ⭐⭐⭐⭐⭐
> Bread ⭐⭐⭐⭐⭐
>
> → Recommend Butter to User B

## Problem 4: Hybrid

Recommend products by combining user characteristics, product characteristics, and user-item interaction behavior.
